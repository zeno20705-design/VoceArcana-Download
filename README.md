# Voce Arcana

Voce Arcana: arena di maghi con gli amici, le magie si lanciano dicendole al microfono in italiano.

**[Scarica Voce Arcana per Windows](https://github.com/zeno20705-design/VoceArcana-Download/releases/latest/download/VoceArcana-Windows.zip)**

Scompatta lo zip e apri `AgeOfSocio.exe`: il launcher controlla da solo gli aggiornamenti
prima di ogni partita e in alto fa scegliere tra Age of Socio, Epoche e Voce Arcana.
Le istruzioni sono nel file `LEGGIMI.txt` dentro lo zip.
